# KIDWISE

เข้าใจทุกวัย ใส่ใจทุกการเติบโต: ต้นแบบแอพติดตามพัฒนาการเด็ก 0–6 ปี สำหรับคุณพ่อคุณแม่

## หน้าจอ

| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าหลัก: การ์ดลูกที่เลือกอยู่, กิจกรรมวันนี้ตามวัย, แจ้งเตือนวัคซีน |
| `menu.html` | เมนูหลัก 6 หมวด |
| `development.html` | พัฒนาการตามช่วงวัย 11 ช่วง × 4 ด้าน (ร่างกาย/สมอง/อารมณ์/ภาษา) พร้อมเช็กลิสต์ |
| `activities.html` | กิจกรรมส่งเสริมพัฒนาการตามวัย ติ๊กเมื่อทำแล้ว |
| `growth.html` | บันทึกน้ำหนัก-ส่วนสูง กราฟเทียบเกณฑ์ WHO แยกชาย/หญิง |
| `nutrition.html` | โภชนาการ ตัวอย่างเมนู และอาหารที่ควรเลี่ยงตามวัย |
| `health.html` | ตารางวัคซีนพื้นฐาน (กระทรวงสาธารณสุข 2569) + วัคซีนเสริม, กำหนดตรวจ DSPM |
| `knowledge.html` | คลังความรู้สำหรับพ่อแม่ 8 เรื่อง และทางเข้าคลังนิทาน |\n| `storybook.html` | คลังนิทานเด็ก 30 เรื่อง แบ่งวัย 0–2, 3–4 และ 5–6 ปี ค้นหา บันทึกรายการโปรด เปิดอ่าน ข้อคิด กิจกรรมต่อยอด และอ่านออกเสียงผ่านเสียงของอุปกรณ์ |
| `notes.html` | บันทึกเรื่องราวของลูก แยกหมวด |
| `profile.html` | โปรไฟล์ลูก: เพิ่ม/แก้ไข/ลบ, เพศ, วันเกิด, รูป, สลับลูก |

## ลูกหลายคน

- ลูกแต่ละคนมีโปรไฟล์ของตัวเอง ข้อมูลทุกอย่าง (พัฒนาการ กิจกรรม น้ำหนัก วัคซีน บันทึก) แยกกัน
- ช่วงวัยคำนวณอัตโนมัติจากวันเกิด: 0–3, 3–6, 6–9, 9–12 เดือน, 1–1.5, 1.5–2, 2–2.5, 2.5–3, 3–4, 4–5, 5–6 ปี
- เพศใช้เลือกเกณฑ์การเจริญเติบโตของ WHO และรูปการ์ตูน (ถ้าไม่ได้ใส่รูป)
- สลับลูกได้จากหน้าโปรไฟล์ หรือแตะรูปลูกคนอื่นที่มุมขวาบนของแต่ละหน้า

## วิธีเปิดดู

ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์ ข้อมูลเก็บในเครื่องด้วย localStorage

## เผยแพร่ด้วย GitHub Pages

1. push โฟลเดอร์นี้ขึ้น GitHub
2. ไปที่ Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`
3. แอพจะเปิดได้ที่ `https://<username>.github.io/<repo>/`

## โครงสร้าง

```
assets/          ภาพ 3D สำหรับแอพ (ย่อขนาดแล้ว)
assets/source/   ภาพต้นฉบับความละเอียดสูง
css/app.css      สไตล์ร่วม
js/stories.js    นิทานต้นฉบับ 30 เรื่อง\njs/storybook.js  ระบบค้นหา อ่านนิทาน รายการโปรด และอ่านออกเสียง\njs/data.js       เนื้อหา: พัฒนาการ กิจกรรม โภชนาการ วัคซีน เกณฑ์ WHO ความรู้
js/app.js        การทำงานของทุกหน้า
```

## แหล่งข้อมูลและข้อควรระวัง

- เกณฑ์น้ำหนัก/ส่วนสูง: WHO Child Growth Standards (เปอร์เซ็นไทล์ 3–50–97) ช่วง 0–5 ปี, ช่วง 5–6 ปีเป็นค่าประมาณ
- วัคซีน: ตารางวัคซีนพื้นฐานกระทรวงสาธารณสุข ปี 2569 รวม PCV ที่เป็นสิทธิฟรีสำหรับเด็กเกิดตั้งแต่ 1 ต.ค. 2568
- รายการพัฒนาการ กิจกรรม และโภชนาการ เขียนตามหลักทั่วไป **ควรให้กุมารแพทย์หรือผู้เชี่ยวชาญตรวจทานก่อนเผยแพร่จริง**

## ติดตั้งลงหน้าจอโฮม (PWA)

- กดปุ่ม **ติดตั้งแอป** ที่หน้าหลัก หรือการ์ดในหน้าโปรไฟล์
- Android/Chrome: ขึ้นหน้าต่างติดตั้งให้ทันที
- iPhone/Safari: แสดงขั้นตอน แชร์ → เพิ่มไปยังหน้าจอโฮม
- ติดตั้งได้เมื่อเปิดผ่าน https (เช่น GitHub Pages) เท่านั้น เปิดจากไฟล์ในเครื่องจะติดตั้งไม่ได้
- หลังติดตั้ง ใช้งานได้แม้ไม่มีอินเทอร์เน็ต (`sw.js`)
- เมื่อแก้ไขไฟล์แล้วอยากให้เครื่องที่ติดตั้งไว้อัปเดตแน่นอน ให้เปลี่ยน `kidwise-v2` ใน `sw.js` เป็นเลขใหม่
