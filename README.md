# KIDWISE

**เข้าใจทุกวัย ใส่ใจทุกการเติบโต** — เว็บแอปภาษาไทยสำหรับคุณพ่อคุณแม่ ใช้ติดตามพัฒนาการเด็กแรกเกิดถึง 6 ปี

## ความสามารถ

- โปรไฟล์เด็กหลายคน: เพิ่ม แก้ไข ลบ และสลับโปรไฟล์ ข้อมูลของแต่ละคนแยกจากกัน
- พัฒนาการ 11 ช่วงวัย × 4 ด้าน: ร่างกาย สมอง/การใช้มือ อารมณ์/สังคม และภาษา
- กิจกรรมส่งเสริมพัฒนาการตามวัย พร้อมบันทึกกิจกรรมที่ทำแล้ว
- การเจริญเติบโต: บันทึกน้ำหนักและส่วนสูง พร้อมกราฟเทียบเกณฑ์ WHO
- สุขภาพ: ตารางวัคซีนและการแจ้งเตือน
- โภชนาการ: แนวทางและตัวอย่างเมนูตามวัย
- คลังความรู้สำหรับผู้ปกครอง
- คลังนิทาน 30 เรื่อง แบ่งช่วงวัย 0–2, 3–4 และ 5–6 ปี ทุกเรื่องมีเนื้อหา 4 หน้า ค้นหา กรองตามวัย บันทึกรายการโปรด อ่านออกเสียงภาษาไทย มีคำถามชวนคิดท้ายเรื่อง และบันทึกนิทานที่อ่านจบลงในโปรไฟล์เด็ก นิทานเรื่องที่ 1 ใช้ภาพประกอบ 3D แยกเป็น 4 ฉาก โดยหน้าอ่านแสดงทีละฉาก ส่วนเรื่องที่ 2–30 จะทยอยจัดทำภาพ 3D เฉพาะเรื่อง เรื่องที่ 1–3 ใช้ภาพประกอบแยกฉากตามหน้าที่อ่าน ส่วนเรื่องอื่นยังอยู่ในคิวจัดทำภาพฉากเฉพาะเรื่อง
- สนามเด็กเล่น 10 เกมสำหรับเด็ก 0–6 ปี: แตะดูภาพสัตว์, จับคู่ภาพ, นับผลไม้, ตามหาพยัญชนะ ก–ฮ, จำแนกสี, จับคู่เงา, เรียงตัวเลข, รู้จักรูปทรง, อะไรหายไป และแยกหมวดหมู่ พร้อมบันทึกผลเกมและดาวเข้ากับโปรไฟล์เด็ก
- รายงานการเรียนรู้ 7 วัน: สรุปกิจกรรม เกม และรายการพัฒนาการที่ผู้ปกครองบันทึก
- กิจกรรมตามวัย: กรองตาม 4 ด้านและดูความคืบหน้าของช่วงวัย

## โครงสร้างโค้ด

- `css/app.css` — สไตล์ร่วมและส่วนประกอบ UI
- `css/games.css` — รูปแบบหน้าสนามเด็กเล่นและการ์ดเกม รองรับมือถือ
- `css/progress.css` — รูปแบบรายงานการเรียนรู้
- `css/storybook.css` — รูปแบบคลังนิทานและหน้าหนังสือ
- `js/app.js` — การทำงานของหน้าเว็บ โปรไฟล์ และการซิงก์ข้อมูล
- `js/games.js` — กลไกเกมฝึกทักษะและส่งผลการเล่นเข้าประวัติโปรไฟล์
- `ROADMAP.md` — แผนพัฒนา KIDWISE ครบ 6 ด้าน
- `js/data.js` — ข้อมูลพัฒนาการ กิจกรรม โภชนาการ สุขภาพ และเกณฑ์การเติบโต
- `stories.js` — ข้อมูลนิทานต้นฉบับ 30 เรื่อง
- `storybook.html` — ฝังข้อมูลนิทานสำหรับ GitHub Pages พร้อมระบบค้นหา อ่านทีละหน้า และอ่านออกเสียง
- `assets/` — ภาพประกอบและไอคอนของแอป
- `icons/` — ไอคอนสำหรับติดตั้งเป็นแอป
- `manifest.webmanifest` และ `sw.js` — การติดตั้ง PWA และการใช้งานออฟไลน์

## บัญชีและการซิงก์ข้อมูล

ปัจจุบันระบบสมัครและเข้าสู่ระบบใช้ **เบอร์โทรศัพท์ + PIN ตัวเลข 4 หลัก** โดยไม่ใช้ OTP ข้อมูลเก็บในเครื่องและซิงก์กับบริการ Cloudflare Worker ภายนอกที่ไม่ได้อยู่ใน repository นี้

การเปลี่ยนเป็นรหัส 4 ตัวอักษรต้องปรับ API ฝั่ง Worker และหน้าเว็บให้รองรับร่วมกันก่อน ห้ามเปลี่ยนเฉพาะหน้าเว็บ เพราะอาจทำให้บัญชีเดิมเข้าสู่ระบบไม่ได้

## เผยแพร่ด้วย GitHub Pages

1. เปิด Settings → Pages
2. เลือก Source เป็น **Deploy from a branch**
3. เลือก branch `main` และ folder `/(root)`
4. เปิดเว็บไซต์จาก URL GitHub Pages ของ repository

## ติดตั้งลงหน้าจอโฮม

- Android/Chrome: เปิดผ่าน HTTPS แล้วเลือกปุ่มติดตั้งแอปหรือเมนู Install app
- iPhone/Safari: กด Share → Add to Home Screen
- Service Worker จัดเก็บไฟล์หลักไว้เพื่อใช้งานออฟไลน์บางส่วน

หลังเปลี่ยนไฟล์ที่ต้องส่งให้เครื่องที่ติดตั้งไว้ ควรเพิ่มเลขเวอร์ชันใน `CACHE` ของ `sw.js` เพื่อบังคับให้ติดตั้ง cache ชุดใหม่

## ข้อควรตรวจทานก่อนเปิดใช้จริง

- ภาพปกนิทานปัจจุบันอาศัยชุดภาพประกอบหลักที่ใช้ซ้ำตามธีม และนิทานเรื่องแรกมีภาพฉาก SVG 4 หน้า การเพิ่มภาพเฉพาะเรื่องให้ครบทั้ง 30 เรื่องยังเป็นงานต่อยอด
- เสียงเล่านิทานใช้ Text-to-Speech ที่ติดตั้งในอุปกรณ์ เสียงและสำเนียงจึงขึ้นกับเบราว์เซอร์/ระบบปฏิบัติการ
- ควรให้กุมารแพทย์หรือผู้เชี่ยวชาญตรวจทานเนื้อหาพัฒนาการ โภชนาการ และสุขภาพก่อนเผยแพร่ต่อสาธารณะ
- เกณฑ์ WHO ที่แสดงเป็นข้อมูลช่วยติดตาม ไม่ใช่การวินิจฉัยทางการแพทย์
