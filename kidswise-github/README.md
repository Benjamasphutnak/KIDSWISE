# คิดส์ไวส์ (KIDSWISE)

เว็บแอปต้นแบบสำหรับส่งเสริมและบันทึกพัฒนาการเด็กแรกเกิดถึง 6 ปี ออกแบบหน้าจอภาษาไทยทั้งหมด พร้อมสไตล์ภาพนูนสามมิติ ใช้สีเขียวมิ้นต์ สีส้ม และสีเหลืองตามเอกลักษณ์โลโก้

## วิธีเปิดใช้งาน
- เปิด `index.html` ในเบราว์เซอร์เพื่อทดลอง
- โปรไฟล์และบันทึกการเติบโตเก็บไว้ในเบราว์เซอร์เครื่องนั้น
- เวอร์ชันนี้ยังไม่มีระบบสมาชิกหรือฐานข้อมูลออนไลน์

## วิธีนำขึ้น GitHub Pages
1. สร้างคลังเก็บ (Repository) ใหม่บน GitHub
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยให้ `index.html` อยู่ระดับบนสุด
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch**
5. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
6. รอให้ GitHub แสดงลิงก์เว็บไซต์

## ไฟล์สำคัญ
- `index.html` โครงสร้างหน้าจอ
- `style.css` รูปแบบหน้าจอและเอฟเฟกต์สามมิติ
- `app.js` การทำงานและการบันทึกข้อมูลในเครื่อง
- `manifest.json` ข้อมูลเว็บแอปสำหรับมือถือ
- `service-worker.js` ระบบเก็บไฟล์ชั่วคราวเพื่อเปิดใช้งานแบบเว็บแอป
- `assets/kidswise-logo.jpg` โลโก้ที่เจ้าของโครงการส่งให้

## หมายเหตุ
นี่คือต้นแบบที่ทำงานในเบราว์เซอร์ ข้อมูลไม่ซิงก์ข้ามอุปกรณ์และไม่มีระบบสำรองข้อมูลออนไลน์ ก่อนเปิดให้ประชาชนใช้งานจริง ควรเพิ่มระบบบัญชีผู้ใช้ ฐานข้อมูลที่ปลอดภัย การจัดการความยินยอมของผู้ปกครอง และให้ผู้เชี่ยวชาญด้านเด็กตรวจสอบเนื้อหาพัฒนาการ


## ภาพแนวทางหน้าจอ
ไฟล์ `ตัวอย่างหน้าจอ-KIDSWISE-3D.png` เป็นภาพอ้างอิงแนวทางหน้าจอสามมิติที่ใช้ในการออกแบบ


## ขั้นต่อไปสำหรับระบบออนไลน์
ดู `SUPABASE-SETUP.md` และ `supabase/schema.sql` สำหรับโครงสร้างฐานข้อมูลเริ่มต้น การเชื่อมต่อจริงต้องสร้างโปรเจกต์ Supabase และตั้งค่าคีย์ก่อน

### ระบบบัญชีรุ่นทดลอง
หน้าเริ่มต้นมีสมัครสมาชิก/เข้าสู่ระบบด้วยเบอร์โทรศัพท์และ PIN 4 หลัก ไม่มี OTP ตามข้อกำหนดเบื้องต้น บัญชีรุ่นนี้เก็บในเบราว์เซอร์เครื่องเดียวเพื่อทดสอบหน้าจอเท่านั้น ยังไม่ใช่ระบบสมาชิกออนไลน์หรือระบบที่ปลอดภัยสำหรับข้อมูลจริง อ่านข้อจำกัดและแนวทางก่อนใช้งานจริงใน `SUPABASE-SETUP.md`.
